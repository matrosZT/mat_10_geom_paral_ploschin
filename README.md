# СтереоАрхітектор: Таємниці паралельних площин (10 клас)

Інтерактивний освітній веб-додаток з геометрії для учнів 10 класу за темою **«Розміщення двох площин у просторі. Ознаки та властивості паралельних площин»** (орієнтований на програму та підручник О.С. Істера).

## Можливості
- **3D-Симуляція №1:** інтерактивне обертання та налаштування кута нахилу і зсуву двох площин у просторі (перетин, паралельність, збіг).
- **3D-Симуляція №2:** лабораторія ознаки паралельності площин та двох властивостей (січна площина $\gamma$ та відрізки паралельних прямих між паралельними площинами).
- **Drag-and-Drop завдання (з підтримкою сенсорних екранів):** сортування істинних/хибних тверджень та конструктор логічного доведення на кубі.
- **Практикум із SVG-кресленнями:** 3 задачі за підручником О.С. Істера з підказками та автоматичною перевіркою.
- **Фінальний PDF-звіт:** фіксація всіх спроб учня, проміжних балів та завантаження PDF на комп'ютер або смартфон.

## Розгортання на GitHub Pages
1. Завантажте файл `index.html` у корінь вашого репозиторію на GitHub.
2. Перейдіть у **Settings → Pages**.
3. У розділі **Build and deployment** оберіть гілку `main` (папка `/ (root)`) та натисніть **Save**.
